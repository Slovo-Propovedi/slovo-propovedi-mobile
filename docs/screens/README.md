# docs/screens — Описание экранов приложения

Папка `screens/` описывает экраны приложения «Слово.Проповеди» (React Native/Expo).

Для каждого экрана здесь фиксируется:

- **что видит пользователь** (элементы UI, состояния),
- **откуда приходят данные** (атомы Reatom, хуки, API, локальная БД),
- **куда можно перейти** (маршруты expo-router с параметрами),
- **статус готовности** (готов / в разработке / заблокирован / заглушка).

Тексты UI — на русском. Ссылки на код указываются конкретными путями (`src/pages/...`, `app/...`).

> **Правило:** при изменении экрана обновляй соответствующий файл в этой папке в том же PR.

## Шаблон файла экрана

```markdown
# <Название экрана на русском>

**Маршрут:** `<путь из app/, например /listen/playlist>`
**Файлы:** `app/(tabs)/listen/index.tsx` → реэкспорт `src/pages/listen/ui.tsx`
**Статус:** готов / в разработке / заблокирован / заглушка

## Что делает

<1–3 предложения: функциональное назначение>

## Что показывается

- <элементы UI: слайдеры, списки, кнопки>

## Откуда данные

- <атомы/хуки/API/локальная БД>

## Куда можно перейти

- <список переходов с параметрами>

## Состояния

- Загрузка: <Skeleton?>
- Пусто: <EmptyState?>
- Офлайн: <поведение>
- Ошибка: <поведение>

## Связанные документы

- [features/...](../features/...)
- [contracts/...](../contracts/...)
```

Простые экраны можно описывать короче — шаблон не обязателен дословно.

## Связанные документы

- Перекрёстные ссылки на другие разделы `docs/` (например, `../features/player.md`, `../contracts/storage.md`) — это планируемые/будущие документы, по мере их создания ссылки оживут.
