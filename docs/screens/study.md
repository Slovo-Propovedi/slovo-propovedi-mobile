# Таб «Учиться»

**Маршрут:** `/study` (экран таб-группы; кнопки в нижнем баре нет)
**Файлы:** `app/(tabs)/study.tsx` → `export { StudyScreen as default }` из `pages/study`
**Статус:** **гейтится фича-флагом `study`** — `CustomTabBar` скрывает маршрут `study` (`HIDDEN_TAB_ROUTE_NAMES`), поэтому экран доступен только прямым переходом/ссылкой; `StudyScreen` не рендерит контент при `useFeatureFlag('study') === false` (см. [features/feature-flags.md](../features/feature-flags.md)). Внутри экрана — заглушка.

## Что делает (планируемое)

Таб обучения. Планируется `TabView` с двумя вкладками. Сейчас экран — каркас с серыми заглушками-страницами.

## Что показывается

`StudyScreen` (`src/pages/study/ui.tsx`) — `TabView` из `react-native-tab-view` с двумя маршрутами:

- «Богословие» (`first`);
- «Душепопечение» (`second`).

Сцены — серые `View`-заглушки: `FirstRoute`/`SecondRoute` из `src/pages/study/scene-routes.tsx`, сборка в `src/pages/study/scene.tsx` через `SceneMap`.

- Кнопка «?» в верхнем ряду экрана (не в нативной шапке) — онбординг/обзор возможностей (см. [../features/onboarding.md](../features/onboarding.md)).

## Откуда данные

- Данные отсутствуют (заглушки).

## Куда можно перейти

- Никуда; экран доступен только прямым переходом при включённом фича-флаге `study` (кнопки в баре нет).

## Состояния

- Экран гейтится фича-флагом `study`: при выключенном/незагруженном флаге `StudyScreen` рендерит `null`; при включённом — контент экрана (заглушки, не предназначенные для показа пользователю).
