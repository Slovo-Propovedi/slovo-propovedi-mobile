# Экран «Проповеди проповедника»

**Маршрут:** `/listen/preacher?artist=<имя проповедника>`
**Файлы:** `app/(tabs)/listen/preacher.tsx` → `export { PreacherScreen as default }` из `pages/preacher` (`src/pages/preacher/ui/PreacherScreen.tsx`, список — `ui/PreacherSermonsList.tsx`, данные — `lib/usePreacherSermons.ts` + `lib/fetchPreacherSermonsPage.ts`)
**Статус:** готов

## Что делает

Постраничный список всех проповедей одного проповедника. Открывается тапом по строке проповедника в выдаче поиска; сессия поиска остаётся открытой под экраном и возвращается в прежнем состоянии по «Назад».

## Что показывается

- Нативная шапка стека «Слушать» с кнопкой «Назад» (фолбэк `/listen`); заголовок — имя проповедника (`useHeaderTitle`), пока оно валидно. «Назад» снимает этот маршрут и возвращает открытый поиск с прежними запросом, группой и страницами выдачи — оверлей поиска всё это время смонтирован под экраном: он остаётся видимым, пока страница въезжает, скрывается после `transitionEnd` стека (запасной порог ~600 мс) и появляется сразу при возврате.
- `FlatList` строк проповедей — те же `SearchResultsRow`/`SermonSearchRow`, что и в поиске: обложка, заголовок, сабтайтл «проповедник • книга+глава+стих», бейдж кэша, прогресс прослушивания, сердечко «в избранном».
- Дозагрузка по достижении конца (`onEndReachedThreshold = 0.4`); футер — `ActivityIndicator`, после ошибки — кнопка «Повторить загрузку».
- Пустое состояние — `EmptyState` «Проповедей пока нет»; первая загрузка — 6 скелетон-строк (`PreacherSermonsSkeleton`).
- Нижний отступ списка — `tabBarHeight + PLAYER_SIZES.miniPlayerHeight`, чтобы последнюю строку не перекрывали таб-бар и мини-плеер.

## Откуда данные

- `artist` из параметров маршрута парсится на границе: `typeof === 'string'`, `trim`, непустая строка, ≤ 200 символов. Невалидный параметр → `EmptyState` «Проповедник не найден», сеть не дёргается.
- `usePreacherSermons(artist)` (`src/pages/preacher/lib/usePreacherSermons.ts`) — курсорная пагинация: `sermonControllerFindAll({ search: artist, take: 20, cursor? })`; первая страница и каждая дозагрузка идут через `fetchPreacherSermonsPage`.
- **Точная фильтрация по `artist` — клиентская:** серверного фильтра по проповеднику нет, а `search` совпадает ещё с заголовком/книгой/описанием. `fetchPreacherSermonsPage` отбрасывает строки, где `artist.trim().toLowerCase()` не равен искомому, и автоматически тянет следующую страницу, пока не наберёт совпадения (не более 10 страниц за один вызов), чтобы не показать ложное «пусто».
- Смена `artist` поднимает поколение (`generationRef`), поэтому устаревший ответ прошлого проповедника не подмешивается к новому списку.
- Per-query кэш поиска не используется (см. [offline-and-network.md](../features/offline-and-network.md) → «Кэш поиска проповедей»); офлайн-фолбэка у экрана нет.

## Куда можно перейти

- Тап по проповеди → воспроизведение через общий `useSermonPlayback`; при неоднозначном контексте сначала открывается пикер `SermonPlaylistPicker`.
- «Назад» → предыдущий экран: при входе из поиска — сохранённая сессия поиска (тот же запрос, группа и страницы), иначе стек «Слушать» (`/listen` при пустой истории навигации).

## Состояния

- Загрузка: `PreacherSermonsSkeleton` (6 строк).
- Пусто: `EmptyState` «Проповедей пока нет».
- Невалидный параметр: `EmptyState` «Проповедник не найден».
- Ошибка: `reportError`, список пуст; дозагрузка — футер «Повторить загрузку».
- Офлайн: первая страница показывает пустое состояние (кэша нет).

## Онбординг

Отдельного тура у экрана нет; сценарий `whatsNew` его не упоминает.
