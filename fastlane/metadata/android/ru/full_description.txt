Слово.Проповеди — свободное открытое приложение для прослушивания и чтения христианских проповедей.

Возможности:
• Воспроизведение плейлистов проповедей с фоновым playback и управлением медиа
• Чтение книг в формате FB2 офлайн
• Настраиваемый URL сервера — без привязки к вендору, работает с любым совместимым бэкендом
• Только локальные уведомления — без проприетарных push-сервисов
• Без отслеживания, без рекламы, без аналитики
• Интерфейс на русском языке
